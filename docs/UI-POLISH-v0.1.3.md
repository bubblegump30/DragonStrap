# DragonStrap v0.1.3 — 4K Glow Controls & Sidebar Cleanup

This pass uses the supplied sidebar-button reference as the quality target.

## Changes
- Removed the sidebar artwork/footer image entirely.
- Added layered matte/glass button surfaces with crisp violet edge lighting.
- Added restrained bloom under and around interactive surfaces.
- Added brighter hover edges and tactile press states.
- Kept text/icons optically sharp; bloom is concentrated on borders rather than glyphs.
- Applied the material system to navigation, launch modes, profiles, action buttons, segmented controls, tiles, and round/icon controls.

The goal is a high-DPI polished control-panel appearance, not a blurry neon effect.

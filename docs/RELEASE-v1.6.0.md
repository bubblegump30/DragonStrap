# DragonStrap v1.6.0 — Server Intelligence 2.0

## Highlights

- Stronger normalized region/metro intelligence from optional RoValra enrichment.
- Persistent seven-day latency history with average/min/max/trend summaries.
- Local favorite-server shortcuts and recent successful server joins.
- Quick JOIN/REJOIN through DragonStrap's validated Roblox deep-link path.
- Occupancy bands, occupancy sorting, open-slot totals, and favorites-only filtering.
- Up to three-server comparison for latency, historical latency, occupancy, uptime, and datacenter.
- Separate Roblox / RoValra-details / RoValra-counts health diagnostics with response timing and failure counters.
- Provider degradation remains fail-soft: Roblox public-server data stays usable if RoValra is unavailable.

## Privacy

RoValra enrichment receives only public lookup identifiers (Place ID and public server IDs). DragonStrap does not send the Roblox authentication cookie. Favorites, recent joins, and latency history remain local.

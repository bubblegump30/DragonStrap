# DragonStrap v2.0.1 — Home Performance Controls Hotfix

v2.0.1 fixes the Home dashboard Performance Center 2.0 card, which was visually interactive but functionally decorative in v2.0.0.

## Functional controls

- FPS opens and focuses the real Performance Center frame-rate controls.
- Render opens and focuses the real renderer controls.
- Network opens Server Intelligence.
- Auto loads the current hardware-aware recommendation and enables pre-launch auto-apply.
- Custom disables auto-apply and opens manual Performance Center tuning.
- The chart opens Performance Center.
- The card reports the live configured FPS target, renderer, profile, and auto/manual state.

The DragonStrap Core API remains `2.0.0`; this is an application hotfix, not a Core API revision.

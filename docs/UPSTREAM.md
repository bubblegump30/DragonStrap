# Upstream Integration Notes

DragonStrap is intended to gain bootstrapper functionality inspired by and, where appropriate, derived from the open-source Fishstrap/Bloxstrap lineage.

Current Fishstrap repository: `fishstrap/fishstrap`.

At the start of DragonStrap v0.1.0, Fishstrap uses a .NET 6 Windows/WPF project and identifies its assembly as Fishstrap. Its repository includes MIT licenses for Fishstrap and Bloxstrap.

DragonStrap v0.1.0 does not vendor the Fishstrap source tree. It establishes the DragonStrap UI and service architecture first. Any later copied or modified upstream source must preserve the applicable license notices.

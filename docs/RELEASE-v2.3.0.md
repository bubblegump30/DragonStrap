# DragonStrap v2.3.0 — Profiles refinement

Launch Center distinguishes its session preset from complete saved configurations and links directly to Profiles. Profiles identifies the last applied profile, previews current differences before enabling Apply, discards stale preview results on selection changes, and shows apply progress and retry feedback. Applying a complete profile remains an explicit operation with existing transactional protections.

Verification: source checks, Node tests, release verification. Windows UI and installer validation require a Windows host.

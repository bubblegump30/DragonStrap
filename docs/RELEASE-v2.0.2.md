# DragonStrap v2.0.2 — Product Menu / Help & About Hotfix

This hotfix makes the top-right DragonStrap identity block functional instead of static.

## Changes

- DragonStrap avatar/name/version block is now a dropdown trigger.
- Added **Help** with internal shortcuts to Launch, Performance Center, FastFlags, and Reliability & Recovery.
- Added **About** navigation to the existing Settings About card.
- Product and About version labels are populated from runtime app metadata.
- Dropdown closes on outside click and Escape.
- Help is a keyboard-accessible native dialog and closes with Escape.
- Core API remains `2.0.0`; no service contracts changed.

## Scope

No installer, updater, FastFlag, Performance, Server, Studio, Profiles, or Recovery backend behavior changed in this release.

# GitHub baseline

Official repository: `bubblegump30/DragonStrap`

`release.config.json` is configured to use this repository for stable GitHub Release checks.

To publish the initial v0.9.5 source baseline from Windows:

```powershell
.\scripts\Publish-To-GitHub.ps1
```

The repository should remain empty before this first push. Do not create an extra README, .gitignore, or license from the GitHub web UI before running the publisher.

# DragonStrap v2.2.0 — Launch Center refinement

The Launch Center previews a Place ID, Roblox game URL, or supported deep link through the same validator used by the launch handler. Invalid targets display an inline reason and cannot be submitted. Quick launch shows actual detected Player and Studio status. Successful handoff is reported as a request rather than a confirmed running process.

Verification: source checks, Node tests, release verification. Windows UI and installer validation require a Windows host.

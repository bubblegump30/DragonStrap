# DragonStrap v2.1.0 — First-run experience

New installations open a four-step setup guide after the initial local installation scan. It reports actual Player and optional Studio detection, explains the production channel, launch readiness, and Recovery. The guide makes no installation or launch changes. Finish saves completion; Remind me next launch leaves it pending. Settings → General can reopen it at any time. Existing settings files migrate as completed.

Verification: source checks, Node tests, release verification. Windows visual and installer validation require a Windows host.

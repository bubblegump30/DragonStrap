# DragonStrap v2.0.3 — Performance Center Layout Hotfix

## Scope

This hotfix removes the unused grid space at the bottom of Performance Center 2.0.

## Changes

- `Applied State` spans two columns on wide three-column layouts.
- `Managed Boundary` occupies the remaining desktop column.
- On two-column layouts the two cards share the full row.
- On one-column layouts both cards stack normally.
- No Performance Center behavior or configuration logic changed.

## Core API

Core API remains `2.0.0`; this is a presentation-only application hotfix.
